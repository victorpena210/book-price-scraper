Setup and troubleshooting

In Spring Tools for Eclipse: Run → Run Configurations → Spring Boot App → ContactTrackerApplication → Environment. Add MELISSA_API_KEY with your new Personator Search license key, then restart the app. Keep your working DB_PASSWORD variable.

In IntelliJ, use Run → Edit Configurations → Environment variables.

GE08 means the key is not enabled for the requested product or level. A configured key must also have Personator Search access. The test stops on this error so it does not repeat the failing request for every name.

UE03 means Melissa rejected the requested page. The queue stops on this error. Download the test results so the page and response-count details can be checked before another batch.

Use Import names above to populate the connected database. Railway has its own database; records saved on your Mac must be imported separately. Keep scraper.run-on-startup=false so imports begin only when requested.

A strict search uses the saved person’s own city and state when available. A matching name alone does not confirm identity. The test requests the first page of up to five candidates and marks when more pages exist.
